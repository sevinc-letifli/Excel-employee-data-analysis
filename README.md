# Excel-employee-data-analysis
Employee data analysis and visualization project using Excel Pivot Tables
# Məqsəd
Bu layihənin məqsədi işçi məlumatlarını analiz edərək işçi davranışında olan əsas tendensiyaları müəyyən etmək, xüsusilə də işdən ayrılmaya təsir edən faktorları araşdırmaqdır.
# Aparılan Analizlər (Pivot Tables)
Korporativ strukturu qiymətləndirmək və insan resursları strategiyalarını optimallaşdırmaq məqsədilə 1000 işçidən ibarət məlumat bazası üzərində aşağıdakı analitik tədqiqatlar aparılmışdır:
1. Şirkət daxilində qadın və kişi işçilərin ümumi paylanma nisbətinin təhlili;
2. Müxtəlif departamentlər üzrə qadın və kişi işçilərin sayı;
3. Müxtəlif yaş qruplarında işçilərin etnik paylanması;
4. Ölkə və şəhərlər üzrə işçilərin ümumi sayına olan faiz nisbəti;
5. Hər department üzrə işdən çıxan işçilərin sayı və onların department üzrə ortalama maaşları;

# İstifadə Olunan Alətlər
- **Microsoft Excel** (Pivot Tables, Data Grouping, Charts)

# Nəticə
Bu layihə Excel alətindən istifadə edərək HR analitikası aparmağın və məlumatlardan praktik nəticələr çıxarmağın mümkün olduğunu göstərir.

# Project Goal
The purpose of this project is to analyze employee data to identify key trends in employee behavior, with a particular focus on investigating the factors that influence employee attrition.


# Conducted Analyses (Pivot Tables)
In order to evaluate the corporate structure and optimize human resources strategies, the following analytical studies were conducted on a dataset of 1000 employees:
1. Analysis of the overall distribution and gender balance of female and male employees within the company;
2. Breakdown of the number of female and male employees across different departments;
3. Ethnic distribution of employees across various age groups;
4. Percentage distribution of employees by country and city relative to the total workforce (Parent Total %);
5. Analysis of employee attrition rate by department, mapped against the average annual salary of each department.

# Tools Used
- **Microsoft Excel** (Pivot Tables, Data Grouping, Charts)
# Conclusion
This project demonstrates that it is possible to perform HR analytics and derive practical insights from data using Excel.
